# Mutants no example can catch, and why each one cannot be caught.
#
# A mutation that changes no behaviour is not a hole in the suite: there is
# nothing to assert against it. Scoring one as a survivor would leave a
# permanent gap in the number and hide the survivors that do mean something.
#
# Each entry names the file, the change, the line, and the line above it. Both
# lines are matched exactly, so editing either brings the mutant back rather
# than leaving a stale entry excusing whatever the code says next.
#
# Add one only after reading the code and finding no observable difference, and
# write down what was found.

why = Nothing reads the document's open flag once parsing has ended. Closing it
